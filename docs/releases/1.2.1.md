A fix for the iOS app, and a lighter build for the server. Nothing changes in the Android app or in how the server runs.

### iOS, built from source

- **Editing with the keyboard open:** the save button and the suggestions under an element being edited stay above the keyboard, instead of hidden behind it. The app makes room for the keyboard as on Android.

### Server

- The server is built without the Ktor Gradle plugin, which nothing used and which brought build tools with known vulnerabilities. The server itself, and its image, run the same libraries as before.
