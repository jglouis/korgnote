A fix for capturing an event from the phone's calendar. Only the Android and iPhone apps change: the server needs no update.

### Capture

- **An event just added in Google Calendar now shows in *Pick an event*.** The list reads the phone's own copy of your calendars, which Google brings up to date only now and then: on one phone, an event added on the web was missing for hours. The picker now asks for that copy to be brought up to date when it opens, and adds the new events to the list as they arrive, while it stays open.
- **On Android, the first time, it asks you to pick your Google account** in Android's *Choose an account* screen. Android ignores a request to update the calendars of an account the app may not see, and picking it once lets KorgNote see it for good. If you cancel, *Fetch new events* in the picker asks again.
