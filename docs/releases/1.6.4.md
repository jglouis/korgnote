Mostly work under the hood: a long look through the code that fixed many bugs in sync and in how notes are read. Please read the first section before you update.

### Before you update

- **KorgNote now needs Android 8 or later.** On Android 7 the app has stopped as soon as you chose where your notes are, since at least 1.2.0, so nobody could be using it there.
- **Notes in dot-folders no longer reach your phones.** Update the server, and anything in a folder such as `.git` or `.stversions`, or behind a link leading out of your notes folder, goes from your phones at the next full sync. The files on the server are not touched. If you edited one on a phone and that edit was never sent, it stays on the phone, but the sync of it fails each time, without saying so.
- **The server no longer ships sample notes.** Started with no notes folder, it serves an empty library and says so.

### Sync

- **Fixed: the agenda crashed on anything repeating by the hour,** such as `+4h`. Each time it falls on a day now also gets its own reminder.
- **Two devices saving the same note at once:** only one wins, and the other merges, where both could be accepted and one edit lost.
- **A conflict copy reaches the server in the sync that made it,** so settling a conflict on this device never deletes the only copy.
- **Saving next to a heading that just arrived now works,** rather than being refused.
- **Edits made while a sync is running stay yours:** an edit saved during a pull, or while the notes reload, is kept. A save after a delete no longer deletes the note on the server, and a note deleted during its first push stays deleted.
- **A change made elsewhere shows up sooner:** the app reads only the notes named in the change, in about half a second.
- **A device that stops reading can't hold up the server.** It catches up with a full sync once it is back.
- **Another device's save no longer fails your sync** with a server error at the moment it writes.

### Notes

- **What is open stays on its heading.** An open drawer, menu or dialog no longer lands on the neighbouring heading when a sync adds one above it.
- **A sync closes a dialog rather than act on the wrong thing.** A reschedule picker or delete confirmation closes when a sync moves what it was about. Nothing is changed, but nothing says why yet either.
- **Delete says what really happens.** Only the KorgNote server keeps a copy of a deleted note. With a folder or WebDAV, the dialog now says that no copy is kept.
- **Org files read more like Emacs reads them:** a heading needs a space after its stars everywhere, an indented keyword counts as one, and an indented `*` list item stays a list item.
- **The link editor:** `example.com:8080` now gets `https://`, rather than being taken for a link to a note.

### Faster

- **Typing** redraws only the element you are editing.
- **Large libraries** sync and open with much less work, and building links and the agenda has moved off the main thread.

### On an iPhone

The iOS app is not part of this release, but if you build it from source:

- **Notes with an accent in their name or folder no longer vanish,** and a new note with an accented title no longer opens empty.
- **On a server on Linux, 1.6.3 could store each such note twice,** under two spellings of its name. Those second copies stay until you delete them, and the phone lists both until then. A server over a Mac folder was not affected.
